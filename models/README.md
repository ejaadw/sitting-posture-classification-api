# Bobot model

Belum ada bobot model karena proyek masih pada tahap proposal.

Setelah training, bagian ini akan memuat:

- Nama dan konfigurasi model terpilih.
- Format bobot dan tautan unduhan Google Drive.
- Cara menempatkan bobot pada folder `models/weights/`.
- Ukuran input, kanal warna, dan normalisasi.
- Pemetaan indeks keluaran ke `Postur Bagus` dan `Tidak Bagus`.

Pemilihan konfigurasi menggunakan data validasi. Metrik data uji dilaporkan setelah evaluasi akhir.
